| Font | Source |
|---|---|
| Inter | rsms/inter (Debian `fonts-inter`) |
| Montserrat | JulietaUla/Montserrat (Debian `fonts-montserrat`) |
| Bebas Neue | Dharma Type (Debian `fonts-bebas-neue`) |
| League Spartan | The League of Moveable Type (Debian `fonts-league-spartan`) |
| Lato | Łukasz Dziedzic (Debian `fonts-lato`) |
| Noto Sans Devanagari | Google Noto (Debian `fonts-noto-core`) |
\nNoto Color Emoji (used for auto-emoji) is installed in the worker image from Debian `fonts-noto-color-emoji`.
